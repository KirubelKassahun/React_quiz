
# React Quiz App

This project is a Quiz Application built using React.js. It allows users to take quizzes on various topics, displays results, and identify correct and incorrect answers.


## Features


- Dynamic Questions: Display quiz questions dynamically fetched from a local or remote source.
- Multiple Question Types: Supports multiple-choice, true/false, and fill-in-the-blank question types.
- Score Calculation: Automatically calculates and displays the user's score at the end of the quiz.

- Responsive Design: Fully functional across devices with a mobile-friendly layout.


### Clone the Repository

To run tests, run the following command

```bash
 git clone https://github.com/kirabelll/React_quiz.git
```

### Navigate to the project directory:


```bash
cd React_quiz
```
### Install Dependencies

```bash
cd React_quiz

```
### Run Server

```bash
npm run server

```
### start the application

```bash
npm run dev

```
